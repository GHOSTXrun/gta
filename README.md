# VICEFRAME web beta

Static web demo and outbound Jupiter trading entry. The archived frontend originated as a NASDUCK snapshot and does not contain upstream source or backend services.

Publish the `main` branch root with GitHub Pages. Check the home, demo, markets, docs and trade pages via direct links and refreshes on mobile and desktop. Demo actions and market preview values should not be relied on for execution. Jupiter handles wallet connection, quotes, signing and execution on Solana mainnet. No PS5 build is distributed by this beta.

Report issues through this repository.
