Four steps

  1. Download

    Take the build for your console. PS5 and PS5 Pro use separate builds.

  2. Verify

    Compare the SHA-256 of your file with the published checksum. If they differ, do not install it.

  3. Install

    Add the build to your console and start GTA VI. The overlay loads with the game.

  4. Link a wallet

    Scan the code the overlay shows with Phantom, Solflare, Backpack or Glow.
